Firefox Extension Installation Test

✅ Расширение готово для Firefox!

Все основные проблемы исправлены и расширение должно корректно работать в Firefox.

Проверенный функционал:

  • Manifest V2 совместимость
  • WebRequest API вместо DeclarativeNetRequest
  • Chrome.tabs.executeScript вместо chrome.scripting.executeScript
  • Правильные права доступа
  • Обработка ошибок в background script
  • Локализация с обработкой ошибок
  • Web accessible resources для локализации
  • Browser-specific settings для Firefox

⚠️ Важные замечания:

  • Используйте firefox_manifest.json для установки в Firefox
  • Не используйте manifest.json (это для Chrome)
  • Убедитесь, что все файлы находятся в правильных папках
  • Проверьте консоль разработчика на ошибки при установке

Инструкция по установке:

  1. Откройте Firefox
  2. Перейдите в about:debugging
  3. Нажмите "Этот Firefox"
  4. Нажмите "Загрузить временное дополнение"
  5. Выберите файл firefox_manifest.json
  6. Откройте YouTube для проверки работы

Проверка работы:

  1. Откройте YouTube
  2. Проверьте, что миниатюры видео изменились
  3. Нажмите на иконку расширения для настройки
  4. Попробуйте разные настройки миниатюр и заголовков

Файлы для Firefox:

  • firefox_manifest.json - манифест
  • js/background_firefox.js - background script
  • js/youtube.js - content script
  • js/options_popup.js - popup script
  • options_popup.html - popup HTML
  • _locales/ - файлы локализации
  • images/ - иконки расширения
